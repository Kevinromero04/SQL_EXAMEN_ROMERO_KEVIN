
# Concesionario CampusCar

## Descripción

Este es una base de datos de un concesionrios donde se guarda vehiculos, usuarios y vendedores.

## Tecnologías Utilizadas

- **SQL**: Para la creacion de la base de datos.


## Tablas

### 1. Tabla vehiculos
- Contiene transmicsion
- Contiene color
- Contiene marca
- Contiene combustible
- Contiene estado
- Contiene Año



### 2. Tabla usuarios
- Contiene Nombre
- Contiene Correo
- Contiene Direccion
- Contiene Telefono

### 2. Tabla vendedores
- Contiene Nombre
- Contiene Fecha de contratacion
- Contiene ventas
